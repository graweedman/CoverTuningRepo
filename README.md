# Cover Tuning Files

A collection of my personal vocal synth tuning files for covers.

## Folders

| Folder | Contents |
| --- | --- |
| [`UTAU/`](UTAU/) | UTAU / OpenUtau project files (`.ust`, `.ustx`) |
| [`Synthesizer V/`](Synthesizer%20V/) | Synthesizer V Studio project files (`.svp`) |
| [`VOCALOID/`](VOCALOID/) | VOCALOID project files (`.vpr`, `.vsqx`) |
